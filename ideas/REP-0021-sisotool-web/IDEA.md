# Sisotool na web: ferramentas para aprender controle

## Registro
Uma espécie de sisotool (a ferramenta do MATLAB) que roda no navegador: um conjunto de ferramentas interativas para ajudar no aprendizado de sistemas de controle. O primeiro produto é o LGR (lugar geométrico das raízes) interativo; a ideia pode crescer para qualquer outra ferramenta que ajude a estudar controle.

## Relato original
> quero adicionar esse lgr interativo para uma ideia do magbrains. a ideia eh basicamente um sistool so que na web. o primeiro produto sera o lgr interativo, mas essa ideia pode expandir para qualquer outro tipo de ferramenta para auxiliar o aprendizado de sistemas de controle.
