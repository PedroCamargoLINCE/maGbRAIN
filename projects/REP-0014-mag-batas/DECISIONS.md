# Decisões de implementação — 2026-11-04

- HTML, Canvas e JavaScript sem dependências: permitir abrir localmente e publicar junto do mapa.
- Três algoritmos procedurais sem API de IA, conforme prioridade do usuário.
- Julia substitui a sugestão inicial de fractal ramificado como primeiro algoritmo fractal; escolha técnica do protótipo, não decisão coletiva.
- Silhueta frontal genérica provisória, pois não foi fornecido molde. Sem alegar prontidão para confecção.
- Logo e texto usam coordenadas relativas à estampa, compartilhadas entre prévia e exportação.
- Publicação depende de revisão e merge; nenhum merge automático.
