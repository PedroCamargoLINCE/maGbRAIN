Plano de ensino

    Como escrever a fórmula
    • Uma linha por média, com nome: MP = media(P1, P2, P3).
    • A última linha é a média final. Ela pode ter nome (MF = ...) ou ser só a conta.
    • Todo nome que você não definir vira uma avaliação para lançar nota: P1, T1, Lista2…
    • Funções: media, soma, min, max e melhores(2; P1, P2, P3), a média das 2 maiores.
    • Pesos como 0,7, 0.7 ou 70%. Os pesos não precisam somar 1: vale o que o plano diz.
    • Com vírgula decimal dentro de funções, separe com ponto e vírgula: max(5,5; P1).
    • Linhas que começam com # são comentários.

    Suas notas ficam só neste navegador. Nada é enviado para lugar nenhum.
